PART 2 — API TESTING WITH Invoke-RestMethod
------------------------------------------------------------

GET root — check server is running:
Invoke-RestMethod -Uri "http://localhost:5000/" -Method GET | ConvertTo-Json

GET all students:
Invoke-RestMethod -Uri "http://localhost:5000/api/students" -Method GET | ConvertTo-Json -Depth 5

GET single student by ID:
Invoke-RestMethod -Uri "http://localhost:5000/api/students/101" -Method GET | ConvertTo-Json

POST — Add new student:
$body = @{ studentId=108; name="Kiran Kumar"; age=21; courseId="CS101"; marks=86 } | ConvertTo-Json
Invoke-RestMethod -Uri "http://localhost:5000/api/students" -Method POST -Body $body -ContentType "application/json" | ConvertTo-Json

PUT — Update student marks:
$body = @{ marks=95 } | ConvertTo-Json
Invoke-RestMethod -Uri "http://localhost:5000/api/students/108" -Method PUT -Body $body -ContentType "application/json" | ConvertTo-Json

DELETE — Remove student:
Invoke-RestMethod -Uri "http://localhost:5000/api/students/108" -Method DELETE | ConvertTo-Json

GET aggregation report — Course Performance:
Invoke-RestMethod -Uri "http://localhost:5000/api/students/reports/course-performance" -Method GET | ConvertTo-Json -Depth 5

GET all courses:
Invoke-RestMethod -Uri "http://localhost:5000/api/courses" -Method GET | ConvertTo-Json -Depth 5

POST — Add new course:
$body = @{ _id="AI101"; courseName="Artificial Intelligence"; department="Computer Science"; credits=4 } | ConvertTo-Json
Invoke-RestMethod -Uri "http://localhost:5000/api/courses" -Method POST -Body $body -ContentType "application/json" | ConvertTo-Json

PUT — Update course credits:
$body = @{ credits=5 } | ConvertTo-Json
Invoke-RestMethod -Uri "http://localhost:5000/api/courses/CS101" -Method PUT -Body $body -ContentType "application/json" | ConvertTo-Json

DELETE — Remove course:
Invoke-RestMethod -Uri "http://localhost:5000/api/courses/DS101" -Method DELETE | ConvertTo-Json


------------------------------------------------------------
PART 3 — MONGODB BACKUP AND RESTORE
------------------------------------------------------------

Create backup folder on Desktop:
New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\Desktop\StudentDB-Backup"

Set MongoDB URI as environment variable:
$env:MONGODB_URI = "mongodb+srv://<MONGODB_USERNAME>:<MONGODB_PASSWORD>@cluster0.aak7tqx.mongodb.net/StudentDB?retryWrites=true&w=majority"

Run mongodump — backup StudentDB:
mongodump --uri="$env:MONGODB_URI" --db=StudentDB --out="$env:USERPROFILE\Desktop\StudentDB-Backup"

Run mongorestore — restore to StudentDB_Restore_Test:
mongorestore --uri="$env:MONGODB_URI" --nsFrom="StudentDB.*" --nsTo="StudentDB_Restore_Test.*" "$env:USERPROFILE\Desktop\StudentDB-Backup\StudentDB"

Verify backup folder contents:
Get-ChildItem "$env:USERPROFILE\Desktop\StudentDB-Backup\StudentDB"
